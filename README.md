## Features

- Advanced board templates optimized for rapid brainstorming, agile sprint planning, customer journey mapping, and professional workshop facilitation.
- Workflow automation scripts (Miro API & Miro Assist prompts) to streamline repetitive sticky note aggregation, voting session management, and frame generation tasks.
- Custom shape packs, icon libraries, and wireframe presets for enhanced visual consistency and rapid UI/UX prototyping directly on the canvas.
- Quick-switch macros and custom keyboard shortcut profiles for seamless navigation between frames, presentation mode, and the left-hand toolbar.
- Pre-configured integration templates for third-party project management and communication apps (e.g., Jira, Asana, Slack, Microsoft Teams).
- Comprehensive documentation and step-by-step setup guides for all included tools, template files (`.rtb` / `.json`), and modules.
- System performance optimization configs for smoother panning and zooming on massive, multi-thousand-item enterprise boards.
- Ready-to-use retrospective and design thinking frameworks with automated timer widgets, icebreaker activities, and action-item extraction routines.

## Requirements

- Windows 10/11 (or macOS)
- Installed Miro Desktop App or a modern web browser with an active Miro account

## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1`) to integrate the custom board templates, widget configurations, and API scripts into your Miro workspace. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced API automation usage, refer to the `GUIDE.md` file included in the archive.

## About the Project

This repository contains the actual enhancement tools, modification scripts, and workflow resources themselves. It is developed to provide users with direct, practical access to functional assets that modify and improve the standard Miro workflow, focusing on educational utility, maximum productivity, and seamless visual collaboration customization for product managers, UX researchers, agile coaches, and remote teams.
